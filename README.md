# موقع ميزان — خطوات الرفع على GitHub Pages

1. افتح github.com وسجّل دخولك، واضغط علامة **+** فوق على اليمين واختار **New repository**.
2. سمّ المستودع **mizan**، خليه **Public**، وسيب كل الخيارات التانية فاضية، واضغط **Create repository**.
3. في الصفحة اللي هتفتح، اضغط على **uploading an existing file**.
4. اسحب كل محتويات الفولدر ده (كل الملفات) وارميها في الصفحة، واضغط **Commit changes**.
5. من تبويب **Settings** وبعدين **Pages** من القايمة اللي على الشمال، في خانة **Branch** اختار **main** واضغط **Save**.
6. بعد دقيقة تقريباً الموقع هيبقى شغال على: `https://adelsamir1942-debug.github.io/mzan-page/` (روابط canonical و og:url و sitemap متظبطة أصلاً على الرابط ده).
7. بعدها ضيف الموقع في Google Search Console (search.google.com/search-console) واطلب فهرسة الصفحة الرئيسية. الظهور في نتايج البحث بياخد من أيام لأسابيع.

محتويات الفولدر:
- index.html — الصفحة نفسها (عربي، RTL، فيها بيانات SoftwareApplication المنظمة لمحركات البحث)
-  — اللوجو، صورة شاشة البرنامج، والفيديوهين مع صورهم المصغرة
- robots.txt و sitemap.xml — ملفات مساعدة لمحركات البحث
